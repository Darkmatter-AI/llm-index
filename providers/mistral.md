## Notes

*   The provided pricing page focuses on subscription plans for the "Le Chat" product, including Free, Pro ($14.99/mo), and Team ($24.99/mo/user) tiers, rather than per-token API rates.
*   Mistral publishes a detailed deprecation and retirement schedule for its legacy models.
*   The documentation provides guidance on model selection, prompting best practices, and options for both cloud and self-deployment.
*   Many models are designated as "Open" or "Premier," indicating different release strategies.
*   The documentation includes a list of legacy models and suggests alternatives for deprecated versions.
