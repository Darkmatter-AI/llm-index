## Notes

*   Asynchronous batch processing is available at a 50% discount.
*   Prompt caching prices are based on a 5-minute Time to Live (TTL).
*   A free usage tier is offered for individuals via the Claude website and apps.
*   US-only data processing is available for a 1.1x price multiplier on input and output tokens.
*   All model IDs are pinned snapshots; there are no evergreen pointers that update automatically.
*   Anthropic maintains a model deprecation policy and schedule.
