## Notes

*   The Batch API provides a 50% discount on processing costs.
*   Prompt caching prices reflect a 5-minute Time-to-Live (TTL).
*   A free tier is available for individual users to try Claude.
*   Workloads requiring US-only inference are subject to a 1.1x price multiplier on input and output tokens.
*   All model IDs are pinned snapshots; they are not evergreen pointers that update over time.
*   Model deprecation schedules are published in the developer documentation.
